# Movie Genre Classification

This project predicts movie genres using Machine Learning and NLP techniques.

## Technologies Used
- Python
- Scikit-learn
- TF-IDF
- Naive Bayes

## Dataset
IMDb Genre Classification Dataset from Kaggle

Dataset Link:
https://www.kaggle.com/datasets/hijest/genre-classification-dataset-imdb

## Accuracy
44.55%

## Run Command

```bash
python movie_genre.py
```
##Output
Model Accuracy :44.55%
Predicted Genre : documentary

- TF-IDF
